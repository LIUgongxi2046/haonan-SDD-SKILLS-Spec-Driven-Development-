# 条件性项目回归清单

仅当当前项目使用对应技术或出现对应历史缺陷时加载，不得作为所有项目的强制清单。

## Vue/uni-app 类项目

- 页面首次加载、watch 依赖、异步数据刷新和组件卸载竞态。
- `navigateTo`、`redirectTo`、`switchTab`、`navigateBack` 与页面导航历史。
- scoped 样式、Portal/遮罩、父容器 overflow 和移动端触控区域。
- 空列表、首尾项、登录失效、快速连点和重复提交。

## 多源数据与迁移

- 同一指标在不同 API/查询中的口径与去重一致。
- seed/主键变化后关联表和历史数据仍可用。
- 分类/枚举重构后的孤儿引用、旧数据与缓存失效。
- 迁移前后行数、关键 JOIN、抽样记录和回滚对账。

## 文件修改与构建安全

- 批量替换前核对影响范围，避免破坏用户未提交修改。
- 修改后运行语法/类型检查和目标页面/接口 smoke test。
- 校验导入、重复声明、样式标签、生成物和意外文件变更。

## 弱网与状态

- 超时、断线、重连、取消、重复事件和部分结果保留。
- UI 不无限 loading；用户可理解失败原因并恢复。

## 身份与动态界面

- 身份显示与稳定 ID 一致，切换后延迟请求、跳转及结果采用不改变目标对象。
- 共享组件根据实际使用范围检查，覆盖结果出现、长内容、弹窗、滚动和固定导航。
- 角色权限同时验证拒绝与合法成功，账号和数据前置可通过真实产品入口建立。

# 实施任务字段

完整范围与状态使用 [交付记录](../../haonan-s000-pmp/references/delivery-ledger.md)。每个任务保留以下信息，按实际任务组织表格或结构化记录。

| 字段 | 要求 |
|---|---|
| `task_id` | 稳定且唯一 |
| 需求来源 | 原始承诺 ID、用户决定、批准需求 |
| `acceptance_ids` | 本任务负责的全部验收动作 |
| 用户结果 | 角色、入口、操作、可观察结果 |
| `depends_on` | 实现依赖；外部、验证和发布条件分别解释 |
| 修改范围 | 允许目录、共享文件归属、禁止改动及用户已有变更 |
| 实施内容 | 满足完整结果的必要步骤，数量由实际工作决定 |
| 业务衔接 | 产出方、使用方、版本、生效时机或合法终态 |
| 验收方法 | 实际操作、预期结果、检查 ID、命令、数据来源及环境 |
| 风险与恢复 | 接口兼容、迁移、权限、幂等和恢复方法 |
| 状态与阻塞 | 任务状态、证据状态、原因、已检查内容和解除条件 |
| 交接 | 当前产物、完整未完成项和下一可执行任务 |

任务依赖无循环，所有承诺均有责任任务。共享前置任务可以独立完成；组合后的模块需要完整验收。子任务回报文件或 `OK` 后，主任务读取产物并验证集成结果。

范围调整必须有用户决定，不能通过改写 DoD、说明或任务名称关闭尚未实现的功能。

# UI 交付 QA 清单

## 范围与追溯

- [ ] 已声明输入模式和事实源。
- [ ] 页面、路由或屏幕总数有可核查分母。
- [ ] 每个必需页面都有需求、路由或原型来源。
- [ ] `INFERRED` 与 `UNKNOWN` 未冒充已确认范围。
- [ ] 阻塞项包含原因和解除条件。

## 状态与流程

- [ ] 核心任务流包含入口、主路径、失败恢复和完成状态。
- [ ] 加载、空、错误、权限、断网、确认、成功和重试均已检查适用性。
- [ ] 危险操作提供明确确认和后果反馈。
- [ ] 长文本、极端数据和多语言不会破坏布局。

## 视觉一致性

- [ ] 页面使用统一 Token、栅格、间距、圆角、阴影和字体层级。
- [ ] 后续页面没有明显降质或脱离母版。
- [ ] IP、插画、图标和场景的比例、材质、光线及色板一致。
- [ ] 不同模块的辅助主题仍保持品牌主体系。

## 可访问性

- [ ] 文本与关键控件对比度可读，状态不只依赖颜色。
- [ ] 键盘焦点清晰，交互顺序合理。
- [ ] 主要触控目标满足目标平台尺寸要求。
- [ ] 图片和图标按钮有语义标签；动画支持减少动态效果。
- [ ] 已检查缩放、大字体和屏幕阅读器关键路径。

## 资产与交付

- [ ] 所有定制视觉都有真实文件，不使用占位符冒充完成品。
- [ ] 清单中的文件存在，未引用孤儿资产已处理。
- [ ] 不同尺寸来自同一 Master，尺寸、格式和透明度正确。
- [ ] 第三方或生成资产记录来源和使用限制。
- [ ] 设计规范、Token、页面稿、状态稿、清单和审计报告齐全。

## 代码落地（如适用）

- [ ] 用户已明确授权修改代码。
- [ ] 未覆盖无关的用户改动，业务逻辑和接口契约保持稳定。
- [ ] 格式化、类型检查、测试和生产构建实际通过。
- [ ] 资产路径无缺失，控制台无新增关键错误。
- [ ] 声称视觉一致时已完成同视口截图对照；否则标记阻塞。

## 报告诚信

- [ ] `PLANNED`、`CREATED`、`OBSERVED`、`VERIFIED`、`BLOCKED` 使用准确。
- [ ] 没有把模板数据、预期结果或人工判断写成已执行结果。
- [ ] 完成声明附带覆盖数量、缺失数量和验证证据。

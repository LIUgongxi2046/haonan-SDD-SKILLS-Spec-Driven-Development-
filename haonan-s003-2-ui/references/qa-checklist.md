# UI 质量检查

## 范围

- 需求和页面分母来自批准范围，代码不存在的页面保留缺口。
- 用户指定平台、修改区域、既有风格及工具限制已继承。
- 共享组件的全部实际使用页面和动态状态已纳入受影响范围。

## 行为与布局

- 核心操作包含入口、前置、结果和错误恢复。
- 加载、空、错误、权限、长内容、结果出现和弹窗状态均检查适用性。
- 滚动、固定导航、标题、浮层和底部区域不会遮挡必要操作。
- 自适应规则匹配可用空间，超出内容有明确滚动方式。
- 键盘、焦点、标签、对比度、缩放和减少动态满足目标平台要求。
- 业务身份、请求和展示结果在切换与跳转时一致。

## 资产与实现

- 只交付任务需要的真实资产，来源、许可、尺寸及引用可核查。
- 实际生成图像时保留工具和源文件证据，不把其他产物写为生成结果。
- 代码修改在授权范围，类型、构建、资源和受影响行为已执行验证。
- 视觉检查遵守用户限制，未执行时不声明视觉一致。

## 报告

分别报告产物、结构、行为和视觉证据，完整列出未验证项。校验器通过不替代真实交互，页面覆盖不替代状态和业务覆盖。

## 逐项交付检查

- [ ] 每个必需页面关联需求、路由或原型来源，全部缺口和推导内容单独记录。
- [ ] 关键流程包含开始、操作、决策、失败恢复与完成状态；危险操作的确认具有适用依据。
- [ ] 长文本、极端数据、多语言、大字体与窄视口均已检查适用性。
- [ ] 后续页面沿用相同 Token、组件、字体、间距、圆角和主题规则。
- [ ] IP、场景、插画及图标的比例、材质、光线和色板符合批准设计。
- [ ] 状态表达包含文字或语义信息，键盘焦点、操作顺序、触控区域和图标标签可验证。
- [ ] 减少动态效果、缩放与屏幕阅读器关键路径具有实际检查记录；未执行项保持可见。
- [ ] 清单引用文件存在，未引用资产得到明确处理，各分辨率、格式及透明度与需求一致。
- [ ] 实际生成的资产记录工具、来源文件、输出文件及 `asset_id`，已有资产记录许可与版本。
- [ ] 全部必需设计规范、页面稿、状态稿、Token、清单与审计报告可打开。
- [ ] 代码修改保留用户范围及既有业务规则，格式、类型、构建、资源引用和受影响行为均有证据。
- [ ] 使用 `PLANNED / CREATED / OBSERVED / VERIFIED / BLOCKED` 时注明检查对象，模板和预期不能写成执行结果。

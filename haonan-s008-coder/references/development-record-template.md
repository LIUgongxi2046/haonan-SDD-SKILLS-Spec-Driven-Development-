# 开发记录模板

本文件定义内容结构。为实际任务创建 Markdown 时用当前事实填写全部适用内容，不把格式示例登记为已执行证据。不适用项说明依据，未知内容保持 `UNKNOWN`。

## 任务身份

| 字段 | 内容要求 |
|---|---|
| `task_id` / 标题 | 稳定任务 ID、业务名称 |
| 需求与验收 | 原始要求来源、FR/BR/AC 或项目既有 ID |
| `task_source` | 唯一任务状态来源路径或链接；单项记录自身为来源时明确说明 |
| 状态快照 | 来源中的任务状态、同步时间、尚未验收范围 |
| 代码与环境 | commit 与未提交修改说明，或实际文件校验和；构建、服务、数据与配置身份 |
| 文档有效性 | `CURRENT / NEEDS_REVIEW`，适用范围、`last_verified`、核实依据 |
| 检索字段 | 模块、业务名称、接口、identifier、相关任务和知识页面 |

## 检索与输入依据

记录本次检索范围、关键词、读取的开发记录及相关代码。每项采用的历史结论说明当前核实依据；无命中时记录结果。关联批准需求、设计、项目规范和必要决策。

## 当前功能与实现

描述用户入口、角色、输入、操作、可观察结果。列出实际处理路径、接口、状态转换、持久化及后续使用方。说明与任务有关的异常、取消、重复操作和权限行为。

| 文件路径 | identifier 或接口 | 当前职责及本任务相关内容 | 调用方与关联流程 |
|---|---|---|---|

## 决策与约束

记录当前采用方式、依据、来源类型及已确认状态，引用相关决策 ID。说明后续修改需要保持的业务规则、兼容语义、环境条件和数据边界。仅记录当前有效结论。

## 验证与证据

| 验收 ID / check_id | 场景与前置条件 | 实际命令或操作 | 预期断言 | 真实结果与状态 | 版本及证据路径 |
|---|---|---|---|---|---|

区分结构、静态、单元、接口、业务、外部接入和 Evals 等证据。记录实际输入来源、账号角色、执行时间和必要运行条件，确保后续可以重复验证。持久化和后续使用行为分别写明断言；未执行项保持真实状态。

## 关联影响与后续使用

列出共享组件、接口调用方、数据关联、配置生效条件、回归入口及相关开发记录。更新受影响文档的当前说明或有效性标记。已有记录被新任务关联时保留稳定路径与任务身份。

## 未完成内容与继续条件

记录尚未通过的验收、缺少的输入、真实阻塞、解除条件和下一可执行动作。全部完成时明确本任务验收范围，并引用唯一任务来源及证据，不使用文档完成代替功能完成。
